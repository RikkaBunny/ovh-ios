# ovh cp 图标

2026-10-03，根据用户要求及其已确认的品牌授权，以保留的 OVH 官方 Apple Touch 图标为参考，使用内置 `image_gen` 工具生成。当前工具不提供具体模型选择，因此未声称指定使用 image2.5。

- `generated.png`：完整生成原图。
- `icon-1024.png`：1024 × 1024、不透明、无预绘外圆角的商店/iOS 图标。
- `prompt.txt`：实际生成提示词。

仅做尺寸导出以生成 Android 的 48/72/96/144/192 px 启动图标；Flutter 连接页面使用相同图标。OVH 官方原始图标仍在上一级目录保存。图标不表示应用由 OVHcloud 官方开发。
