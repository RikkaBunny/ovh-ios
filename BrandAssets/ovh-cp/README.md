# OVH CP 图标

2026-10-03，根据用户要求及其已确认的品牌授权，以保留的 OVH 官方图标为参考，使用内置 `image_gen` 工具生成。当前工具不提供具体模型选择，因此未声称指定使用 image2.5。

当前版本为白底蓝标，保留既有标志形状、cp 字样和浅蓝色点缀：

- `generated-white.png`：白底版完整生成原图（1254 × 1254、RGB）。
- `icon-white-1024.png`、`icon-1024.png`：当前 1024 × 1024 不透明商店/iOS 图标，无预绘外圆角。
- `prompt-white.txt`：白底版实际生成提示词。
- `generated.png`、`prompt.txt`：此前蓝底白标的原图与提示词，保留作历史参考。

仅做尺寸导出，统一用于 iOS、Android 自适应与传统启动图标、启动画面、Flutter 连接页以及官网。Android 自适应图标背景配置为白色。OVH 官方原始图标仍在上一级目录保存。图标不表示应用由 OVHcloud 官方开发。
