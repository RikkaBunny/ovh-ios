# OVH 图标来源

按用户要求采用 ovh.com 官方网站图标。2026-10-02，`https://www.ovh.com/` 跳转至 `https://www.ovhcloud.com/en/`，页面声明以下图标资源：

- 矢量图标：<https://www.ovhcloud.com/icon.svg>
- Apple Touch 图标：<https://www.ovhcloud.com/apple-touch-icon.png>

保留两份原始资源。iOS 图标使用相同标记、白色前景和官方 Touch 图标的深蓝背景（#000e9c）。使用矢量轮廓生成 1024 × 1024 不透明 PNG，沿用原 Touch 图标的居中比例；不预绘圆角，由 iOS 处理外形。

本客户端是个人自建面板客户端，图标引用不表示 OVHcloud 官方发布或认证。
