使用前置条件

先在自己的 VPS 上部署 OVH 服务

OVH CP 基于开源项目 gokele/ovh 开发，连接由你自行部署的网页面板与服务。请先在自己的 VPS 上安装该项目、配置 OVH 账户，并准备可通过 HTTPS 访问的面板地址，再进行 App 配对。

请使用带有「API 设置 → App 配对」入口的服务版本；如果看不到此入口，请先更新服务。

OVH 服务项目 ↗ 查看部署文档 ↗
01

部署服务并安装 App

先在自己的 VPS 部署 gokele/ovh 服务并配置 OVH 账户。确认网页面板可通过 HTTPS 访问后，再安装手机 App。

02

生成配对码

在网页「API 设置 → App 配对」生成二维码或 8 位码。OVH API 凭据由自己的后端管理，配对时无需再次录入。

03

扫描连接

在 App 扫码、选择二维码图片，或输入面板地址与 8 位码。连接后共用账户、队列、监控与设置；也可在 App 管理 API 配置。

常见问题

使用 App 前需要准备什么？
需要自己的 VPS，并先安装 gokele/ovh 服务项目、配置 OVH 账户与可通过 HTTPS 访问的网页面板。确认网页「API 设置 → App 配对」入口可用后，再生成配对码连接 App。安装方法见 项目部署文档。
这是 OVHcloud 官方应用吗？
OVH CP 是支持 OVHcloud 的独立开源客户端，非 OVHcloud 官方开发。它基于 gokele/ovh，需要连接你在自己的 VPS 上部署的该项目服务，与网页共用管理数据。
如何申请 iOS 测试？
请前往 联系页，留下接收邀请的邮箱，并注明申请 OVH CP 的 iOS 测试。开发者会通过该邮箱邀请你加入 TestFlight；收到邀请后，可在 iPhone 或 iPad 上通过 TestFlight 安装应用。
App 如何连接我的后端？
App 通过 HTTPS 访问配对的面板后端，无需额外注册开发者账号。OVH API 凭据由该后端管理，App 的账户与 API 设置也可以读写这些配置。请在自己的网页控制台管理已授权设备。
首页的资源占用属于哪台服务器？
资源属于 App 中选定账户下的具体实例，可以切换独立服务器或 VPS。已接入监控的实例显示实际读数，尚未接入时显示未知，不会借用另一台机器的数据。
