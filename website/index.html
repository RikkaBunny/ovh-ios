01

安装 App，打开网页

安装 APK，按 Android 提示允许当前下载来源安装应用。打开已部署、支持 App 配对接口的 HTTPS 网页面板。

02

生成配对码

在网页「API 设置 → App 配对」生成二维码或 8 位码。OVH API 凭据由自己的后端管理，配对时无需再次录入。

03

扫描连接

在 App 扫码、选择二维码图片，或输入面板地址与 8 位码。连接后共用账户、队列、监控与设置；也可在 App 管理 API 配置。

常见问题

这是 OVHcloud 官方应用吗？
OVH CP 是支持 OVHcloud 的独立开源客户端，非 OVHcloud 官方开发。它需要连接你自己的 gokele/ovh 后端，与网页共用管理数据。
iOS 版本什么时候可以下载？
iOS / iPadOS 1.3.0 已提交 App Store 审核。这里的 iOS 入口指向 GitHub 发布信息，商店下载链接会在确认上架后更新。
App 如何连接我的后端？
App 通过 HTTPS 访问配对的面板后端，无需额外注册开发者账号。OVH API 凭据由该后端管理，App 的账户与 API 设置也可以读写这些配置。请在自己的网页控制台管理已授权设备。
首页的资源占用属于哪台服务器？
资源属于 App 中选定账户下的具体实例，可以切换独立服务器或 VPS。已接入监控的实例显示实际读数，尚未接入时显示未知，不会借用另一台机器的数据。
