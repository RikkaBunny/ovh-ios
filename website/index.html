常见问题

安卓安装提示“暂不允许安装”，怎么办？
按系统提示允许当前浏览器或文件管理器安装应用，再重新打开下载好的 APK。不同品牌手机的菜单名称可能有所不同。
更新需要重新配对吗？
同一签名的正式版可以覆盖安装并保留连接。开发测试包签名不同，需要先卸载测试版，再安装正式版并重新配对。
这个 App 是 OVHcloud 官方的吗？
不是。ovh cp 是由独立开发者 jingcheng he 开发并采用 AGPL-3.0 协议开源的第三方客户端，旨在为您提供更好的移动端管理体验。它与 OVHcloud 公司无官方关联。
为什么首页不显示每台 VPS 的 CPU/内存使用率？
仪表盘的资源数据来自运行 gokele/ovh 面板的宿主机。它反映面板主机的负载，不代表每一台 OVH 实例内部的系统指标。
我可以在不部署网页后端的情况下单独使用 App 吗？
不可以。ovh cp 被设计为 gokele/ovh 系统的前端扩展，它依赖后端的账户管理、队列调度与 API 通信能力。请务必先部署后端控制台。
