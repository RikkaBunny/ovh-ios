App: OVH CP 1.3.0 (15), Bundle ID com.hejingcheng.ovhpocket.

Build 15 fixes Dashboard resources that previously showed the panel host across all accounts. Gauges now belong to the selected account and instance, with an instance selector, scoped caching, response identity checks, and explicit unknown values when monitoring is unavailable. The deployed extension authenticates through the existing backend and validates instance ownership. It only collects the explicitly bound panel-host instance; other production instances require their own monitoring source. The isolated review backend provides synthetic per-instance readings. The React-inspired Flutter UI, white icon, uppercase name, queue/resources placement, and Servers instance tab are retained. Data handling and backend authentication remain unchanged.

This update replaces the existing OVH client's interface with a Flutter mobile client while preserving the original application identity. Its initial connection can migrate existing on-device credentials. It uses the same self-hosted backend as the web console. Business screens are built in Flutter; only the OVH-provided remote KVM screen is a WebView. It is not a webpage wrapper.
