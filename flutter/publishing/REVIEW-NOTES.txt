App: ovh cp 1.3.0 (11), Bundle ID com.hejingcheng.ovhpocket.

This update replaces the existing OVH client's interface with a Flutter mobile client while preserving the original application identity. Its initial connection can migrate existing on-device credentials. It uses the same self-hosted backend as the web console. Business screens are built in Flutter; only the OVH-provided remote KVM screen is a WebView. It is not a webpage wrapper.

For review, use the isolated demonstration backend:
Panel URL: https://ovh-review.hejingcheng.com
Panel access key: OVH-AppReview-2026

The value above is a public test credential for synthetic servers, not an OVH account credential. No OVH login, two-factor code, subscription, payment or real infrastructure is required. Choose 'use legacy access key' on the initial page to enter it. The review website also generates temporary QR pairing codes at https://ovh-review.hejingcheng.com/review .

Test the Dashboard, Servers, Queue, Monitor and More tabs, switch EU/CA/US demo accounts, inspect dedicated servers and VPS, and use simulated controls. CPU/memory/storage gauges describe the panel host. Reinstall/termination actions require typed service names; all demo effects are simulated. Disconnect is at the bottom of the connection settings. Scanning or selecting a pairing image is optional because manual pairing and access-key entry are available.
