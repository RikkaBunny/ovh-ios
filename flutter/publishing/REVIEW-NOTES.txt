App: OVH CP 1.4.0 (16), Bundle ID com.hejingcheng.ovhpocket.

This update synchronizes the mobile client with gokele/ovh v0.4.3. It adds prerelease catalog search and preorder selection, configuration-specific monitor pause/resume, official OVH order history, and template-specific reinstall configuration. It improves request error handling so an OVH business API error does not incorrectly disconnect a valid panel session. Some functions depend on the connected self-hosted backend version and OVH account permissions. The app still connects to the same user-hosted backend as the web console. Business screens use Flutter; only the OVH remote KVM screen uses a WebView. There are no new analytics, advertising, payment, or tracking SDKs in this update.
