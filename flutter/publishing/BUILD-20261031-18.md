# iOS 1.5.0 (18) 审查修复与本地构建

日期：2026-10-31。OVH CP，Bundle ID `com.hejingcheng.ovhpocket`，最低 iOS 17.0。接口基线仍为 gokele/ovh v0.4.12、238 项。

## 修复

- 监控按接口分别核对能力：新版编辑/暂停支持配置选择，不把它推断为删除/历史也支持。空配置歧义删除、多配置历史保留保护；执行层拦截旧页面绕过。
- iOS 官方客服从活动 Scene 的窗口展示，等待打开/关闭完成；原生窗口失败不再误报为 API 权限问题。
- 运行中任务编辑先读取最新队列、核对账户和状态，再暂停、保存；暂停失败、任务完成或连接改变时停止。保存后保持暂停，迟到的旧刷新不能覆盖最新状态。
- 联系人变更解析后端 data 结构并绑定 task_id，恢复列表、详情以及接受/拒绝/重发邮件操作。
