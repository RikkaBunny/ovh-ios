# OVH / ovh cp 隐私政策

更新日期：2026 年 10 月 3 日。开发者：jingcheng he。

OVH 与 ovh cp 是自建 gokele/ovh 面板的移动客户端。ovh cp 运行于 iOS、iPadOS 和 Android，直接连接你选择的 HTTPS 面板。开发者没有运营集中用户账户、广告、追踪、分析或崩溃报告服务。面板地址、令牌、服务器信息及二维码图片不会发送到开发者的数据收集服务。

你自己的面板运营者和其 OVH 账户会处理服务信息、授权的设备名称及管理操作，适用该后端的存储、删除、日志与安全政策。请只连接可信的面板。面板操作可能控制服务器或产生订单；客户端会显示操作确认及目标。

访问密钥或设备令牌在 iOS 存入设备专属 Keychain，在 Android 存入 flutter_secure_storage 提供的本机安全存储。账户选择与外观保存在本地；Android 系统备份关闭。iOS 由原 OVH 应用更新时，仅在本机迁移同一应用中的面板令牌、账户选择与外观；成功保存新令牌后清除旧存储，不读取其他应用的凭据。

相机仅用于扫描你自建面板的配对二维码。系统图片选择器只提供你选择的二维码图片，解码在本机进行，不上传图片。远程 KVM 页面加载 OVH 返回的 HTTPS 页面，并适用该服务的隐私政策。应用不读取通讯录、位置或广告标识符。

Android 扫码组件使用 Google ML Kit。Google 说明该 SDK 会通过 HTTPS 收集设备及应用版本信息、每次安装的标识符、扫描配置、性能指标及错误信息，用于诊断和使用分析。二维码图像及解码结果仍在本机处理。iOS 扫码使用 Apple 的本机接口，不使用 Android ML Kit。参见 [Google ML Kit 数据披露说明](https://developers.google.com/ml-kit/android-data-disclosure)；Android 商店数据安全申报会单独披露这些 SDK 数据。

断开连接会删除本机凭据。要使服务器端的设备令牌失效，请在网页“API 设置 → App 配对”撤销相应设备。应用不创建额外的开发者用户账户。

ovh-review.hejingcheng.com 是隔离的审核演示后端，仅含合成账户、服务器与文档示例 IP，不连接 OVH，不执行真实购买、电源操作或删除。临时演示设备名称、令牌及状态只在内存中保留，服务重启后清除；请求 IP、请求内容及凭据日志关闭。
